### 🌟 Featured Project

#### 🔍 [Clarifex — Autonomous QA Assistant for Web & Agent Plugins](https://github.com/PromptCraft-TH/Clarifex)
* **What it is:** A reusable, evidence-backed QA assistant packaged as a portable Agent Plugin (compatible with **Google Antigravity**, **Claude**, and **OpenAI**).
* **Key Strengths:**
  - ⚡ **Zero Runtime Dependencies** — pure Python 3.9+ standard library.
  - 🔒 **Trust-First & Local-First** — strictly zero telemetry, POSIX evidence layer, and bounded repair limits.
  - 🧪 **100% Tested** — comprehensive test matrix with 198 unit tests and continuous CodeQL security scanning.
